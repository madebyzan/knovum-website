title: Your first Space
description: Turn a small set of sources into an answer you can verify.
---

## Pick a bounded task

For example: “Why did people stop using our trial?” Use a short interview recording, a saved article and your own notes. This is a workflow example, not a built-in template.

## Collect and organize

1. Open the library and create a Space with a meaningful title.
2. Add a note containing your question.
3. Use **Add Website**, **Import Files** or **Audio Note** to bring in sources.
4. Wait for relevant import or transcript tasks to complete.
5. Put related material in a Section. Use a Group when you want to move a set together.

Inbox is the permanent capture destination for material you have not organized yet. You can move its content into a project Space later.

## Ask and inspect

Select the sources you want to use, then open the question/conversation surface with that scope. Choose an available configured executor when the operation requires one. Ask the bounded question, open the answer’s citations and compare them with the source.

A fluent answer is not proof. Missing transcripts or unextracted document text reduce the available evidence; a citation to an old revision is historical evidence, not a live statement about the changed source.

## Preserve the result

Write your conclusion in a note or create a document from the selection. Export the complete Space as a `.knovumspace` package before transferring it to another computer. Exporting one document is not a backup of the Space.
