title: Keyboard shortcuts
description: Every Knovum shortcut, grouped by where you use it.
---

<kbd>⌘/Ctrl</kbd> below means <kbd>⌘</kbd> on a Mac and <kbd>Ctrl</kbd> on Windows. In the app, press <kbd>⌘/Ctrl</kbd> + <kbd>/</kbd> at any time to view and search shortcuts.

## General

| Keys                                                | Action                       |
| --------------------------------------------------- | ---------------------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>K</kbd>                    | Command palette              |
| <kbd>⌘/Ctrl</kbd> + <kbd>/</kbd>                    | Keyboard shortcuts           |
| <kbd>⌘/Ctrl</kbd> + <kbd>,</kbd>                    | Settings                     |
| <kbd>⌘/Ctrl</kbd> + <kbd>B</kbd>                    | Show or hide the sidebar     |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> | Show or hide the right panel |

## Spaces and tabs

| Keys                                                | Action            |
| --------------------------------------------------- | ----------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>T</kbd>                    | New Space         |
| <kbd>⌘/Ctrl</kbd> + <kbd>W</kbd>                    | Close tab         |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> | Reopen closed tab |
| <kbd>⌘/Ctrl</kbd> + <kbd>1</kbd>–<kbd>9</kbd>       | Go to tab N       |
| <kbd>Ctrl</kbd> + <kbd>Tab</kbd>                    | Next tab          |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd>        | Back / forward    |

## Find and ask

| Keys                                                | Action                    |
| --------------------------------------------------- | ------------------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd>                    | Find in the current Space |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Search all Spaces         |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | Outline                   |
| <kbd>⌘/Ctrl</kbd> + <kbd>Enter</kbd>                | Ask about the selection   |

## Canvas tools

While you are typing, these single keys go to the text instead of switching tools.

| Key          | Tool         |
| ------------ | ------------ |
| <kbd>V</kbd> | Select       |
| <kbd>H</kbd> | Pan          |
| <kbd>N</kbd> | New note     |
| <kbd>T</kbd> | Text         |
| <kbd>S</kbd> | Draw section |

You can also pan by holding <kbd>Space</kbd> and dragging, or by dragging with the middle mouse button.

## Canvas editing

| Keys                                                           | Action                   |
| -------------------------------------------------------------- | ------------------------ |
| <kbd>⌘/Ctrl</kbd> + <kbd>Z</kbd>                               | Undo                     |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd>            | Redo                     |
| <kbd>⌘/Ctrl</kbd> + <kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy / cut / paste       |
| <kbd>⌘/Ctrl</kbd> + <kbd>D</kbd>                               | Duplicate                |
| <kbd>⌘/Ctrl</kbd> + <kbd>A</kbd>                               | Select all               |
| <kbd>Delete</kbd> (<kbd>Backspace</kbd> on a Mac)              | Delete selection         |
| <kbd>F2</kbd>                                                  | Rename                   |
| <kbd>⌘/Ctrl</kbd> + <kbd>G</kbd>                               | Group selection          |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd>            | Ungroup                  |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd>            | Lock or unlock selection |
| Arrow keys                                                     | Nudge selection          |
| <kbd>Shift</kbd> + arrow keys                                  | Move 10 px               |
| <kbd>Esc</kbd>                                                 | Cancel canvas operation  |
