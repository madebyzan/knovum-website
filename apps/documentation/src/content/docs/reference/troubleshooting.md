---
title: Troubleshooting
description: Diagnose the affected boundary without deleting your library.
---

## A model operation is waiting

Check Task Center for download, verification, queued execution or a failed task. First use can require large downloads. Verify network access and disk space, then retry the failed operation. A cancelled shared preparation need not cancel another task using the same model.

## Search does not find a source

Try keywords first. Verify the file import/extraction or recording transcription completed. Semantic search also requires a prepared embedding model and current index. A filename match is not proof that the document body has been extracted.

## AI generation fails

Check the selected executor, credentials and operation compatibility. Authentication failure, rate limiting, unsupported image editing and local model preparation are distinct problems. Do not send sensitive content to another service simply to work around an error.

## Export is unavailable

Wait for pending resource preparation. Check the formats actually offered for that content. Unsupported document structures or missing source assets can block conversion. Preserve the original and use its associated editor if exact layout is required.

## Cannot delete or move a resource

Close document/video tabs that reference it and resolve unsaved work. An occupied editing session protects the resource; this is not a reason to remove files directly from application storage.

## Startup or installation error

Keep the displayed error details and the application version. Download from the official source; do not bypass Gatekeeper or SmartScreen routinely. Reset Settings is an explicit recovery action that clears settings and saved provider credentials while keeping Space content, so understand its effect before choosing it.

When reporting an issue, include the platform, version, steps and error message. Redact credentials, personal source content and exported private paths. Never delete the database as a normal user troubleshooting step.
