## 选择安装包

| 电脑           | 系统要求                            | 安装包         |
| -------------- | ----------------------------------- | -------------- |
| Apple 芯片 Mac | macOS 14 及以上                     | Apple 芯片 DMG |
| Intel Mac      | macOS 14 及以上                     | Intel DMG      |
| Windows 电脑   | Windows 10 版本 2004（19041）及以上 | x64 安装程序   |

不确定 Mac 是哪种芯片：点屏幕左上角的苹果菜单，选「关于本机」，看「芯片」一栏。Linux 和 Windows ARM 暂不支持。

## 安装

从 Knovum 官网（本页右上角的「官网」）或 [GitHub 发布页](https://github.com/madebyzan/knovum/releases)下载安装包。

- **macOS**：打开 DMG，把 Knovum 拖进「应用程序」文件夹，再从「应用程序」里启动。
- **Windows**：运行 x64 安装程序，按向导完成。

:::caution[安装包提示损坏或未验证]
停下来，重新从上面的官方地址下载。不要为了装上而关闭 Gatekeeper 或 SmartScreen。
:::

## 第一次打开

简体中文界面中，应用名显示为「知生知」。

打开后就能新建空间、写笔记、导入资料和搜索，都不需要任何 AI 账号。本地模型不会随安装一次性下载：第一次用到转录、语义搜索等功能时，Knovum 才下载对应的模型，并在「任务」面板里显示进度。这一步需要联网和一些磁盘空间，之后模型就在本机运行。

想让 Knovum 回答问题、生成文档，再去[配置 AI 服务商](../../guides/providers/)或[桌面 Agent](../../guides/agents/)。

## 更新

Knovum 在启动后和之后每六小时检查一次更新。发现新版本时，你可以先看更新说明，再决定是否下载；下载的更新包会验证签名，确认后重启安装。更新不会改动你的资料库。
