## 选择版本

| 电脑           | 系统要求                                  | 安装包         |
| -------------- | ----------------------------------------- | -------------- |
| Apple 芯片 Mac | macOS 14 及以上                           | Apple 芯片 DMG |
| Intel Mac      | macOS 14 及以上                           | Intel DMG      |
| Windows 电脑   | Windows 10 版本 2004 / build 19041 及以上 | x64 安装程序   |

Linux 和 Windows ARM 不在发布支持范围内。Mac 可在“关于本机”中确认芯片类型。

## 安装

从 Knovum 官网或[产品发布页](https://github.com/madebyzan/knovum/releases)下载安装包。

- **macOS**：打开 DMG，将 Knovum 拖入“应用程序”，再启动安装后的应用。
- **Windows**：运行 x64 安装程序，按向导完成安装。

如果系统提示安装包损坏或未验证，先停止安装并核实下载来源。不要把关闭系统安全保护当作正常安装步骤。

## 首次使用

打开 Space、写笔记不需要服务商密钥。应用安装不会一次下载所有本地模型；首次启动需要模型的功能时才会准备，并在任务中心显示进度。首次准备需要联网和磁盘空间，安装完成后的推理在本机执行。

应用升级和资料库是两件事。跨电脑迁移或调整重要安装环境前，先导出重要 Space。
