---
title: 建立第一个空间
description: 一个问题、两份资料、一个你亲自核对过的结论。十分钟走完 Knovum 的完整流程。
---

这篇教程用两份资料回答一个问题，走完 Knovum 最核心的一圈：收集资料、自己先读、向资料提问、逐条核对引用、写下结论。

:::note[需要准备]
一篇文章的网址或一份文档，再加一份讨论同一问题的资料。导入、整理和搜索都不需要 AI 账号；第 5 步提问需要先[配置 AI 服务商](../../guides/providers/)，或启用一个[桌面 Agent](../../guides/agents/)。
:::

本例的问题是：**为什么用户试用后不再继续？** 换成你自己的问题也完全可以。

## 1. 新建空间

按 <kbd>⌘/Ctrl</kbd> + <kbd>T</kbd>「新建空间」，重命名为「试用研究」。

双击画布空白处，新建一张便签，写下问题，以及什么样的回答才算数：

> 问题：为什么用户试用后不再继续？
> 需要：具体原因、每个原因的出处，以及目前还不知道什么。

:::tip[检查点]
画布上有一张写着问题的便签。先别急着把所有资料都放进来，两份就够走通流程。
:::

## 2. 放入资料

在画布上打开「添加内容」：

- 网页：选「添加网页」，粘贴网址。Knovum 保存链接，并抓取标题、摘要和可读的正文。
- 文件：选「导入文件…」，或者直接把文件拖到画布上。PDF、Word、PowerPoint、Markdown 都可以。

点开每一份资料，确认能读到正文，而不只是一个标题。PDF 和 Office 文档的文字提取在后台进行，进度显示在「任务」面板里。

:::tip[检查点]
两份资料都能打开，并且读得到你打算引用的段落。
:::

## 3. 圈出这次要用的资料

选中两份资料，右键选「创建分区」，命名为「证据」。之后提问时，一次选中这个分区就能带上里面的全部资料。

资料多起来后，用侧栏的「大纲」找东西：点任意一项，画布就会定位过去。

## 4. 自己先找到一段原文

按 <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd> 打开「查找」，搜一个你预期会出现的词，比如「价格」或「导入」。打开结果，读一读命中的段落。

在提问之前先亲自读过一段原文，你才有底气判断 Agent 的回答靠不靠谱。

## 5. 向资料提问

打开「对话」面板，在「选择 Agent」里选 **Knovum Agent** 或一个已启用的桌面 Agent。选中「证据」分区，点「添加资料」→「添加当前选中」，然后输入：

> 这些资料提到了哪些放弃试用的原因？
> 每个原因都附上支持它的原文。
> 区分资料的原话和你的推断；资料之间有冲突或信息不足时，直接说明。

回答下方会列出「来源」。逐条点「定位至来源位置」，对照原文问自己一句：原文真的这么说了吗？

:::tip[检查点]
回答里每一个你打算采用的判断，你都亲眼看过它的原文。对不上的，删掉或标为待确认。
:::

## 6. 写下结论

觉得某段原文值得留下，用「摘录为证据」把它变成画布上的一个证据对象。

在「证据」分区旁边新建一张便签，分三部分写：**资料支持什么**、**还不确定什么**、**下一步做什么**。

想把论证记得更严谨，可以为每个结论建一个观点，再用「支持」或「反证」连到对应的证据，做法见[结构化知识](../../guides/knowledge/)。需要一份正式文档，就选中这些资料，[用选中项创建](../../guides/creation/)。

## 遇到问题先查哪里

| 现象                 | 先检查                                                         |
| -------------------- | -------------------------------------------------------------- |
| 导入的文档只有标题   | 「任务」面板里的文档内容提取是否完成                           |
| 搜不到录音里说过的话 | 录音是否已经转录                                               |
| 找不到「语义搜索」   | 第一次使用需要下载本地模型，见[查找资料](../../guides/search/) |
| 对话里选不到 Agent   | 模型是否开启了「用于内置 Agent」，或桌面 Agent 是否已启用      |
| 引用和原文对不上     | 资料是否在回答之后被修改过                                     |
