Knovum 的词不多，但每个都对应界面上一个具体的东西。先认识它们，再去动手。

## 空间与收集箱

**空间**是围绕一件事的工作区：一个研究课题、一个项目、一门课。资料、笔记和结论放在同一张无限画布上，互相挨着，也互相连着。按 <kbd>⌘/Ctrl</kbd> + <kbd>T</kbd> 新建空间。

**收集箱**是一个特殊的空间，用来随手收东西。还没想好归到哪里的网页、文件和想法先放这里，之后用「移动至空间」挪到对应的空间。

## 资源

画布上的每一样东西都是一个资源：便签、文字、Markdown 文档、网页、图片、音频、视频、文件和代码。

导入文件时，Knovum 会把文件复制一份存进自己的资料库。你电脑上的原文件保持原样，两者之后不会互相同步。

## 整理画布

| 名称     | 做什么                                       |
| -------- | -------------------------------------------- |
| **分区** | 画布上有名字的一块区域，把相关资料放在一起。 |
| **组合** | 把几个对象编成一组，一起移动、一起操作。     |
| **标签** | 与位置无关的标记，用来筛选。                 |
| **场景** | 保存当前视口，之后一键回到这块区域。         |
| **大纲** | 侧栏里的全部内容列表，点一项就能定位。       |

## 对话与 Agent

向资料提问在「对话」面板里进行。回答由你选择的 Agent 完成：

- **Knovum Agent**：内置 Agent，使用你在「AI 服务商」里添加、并开启了「用于内置 Agent」的模型。
- **桌面 Agent**：这台电脑上已安装并登录的工具，例如 Claude Code、Codex 或 Gemini CLI，使用它们自己的账号。

## 引用

Agent 回答时会列出「来源」。每条来源指向确切的位置：PDF 的某一页、文档的某一段、录音的某个时间段、代码的某几行。点「定位至来源位置」，直接打开原文。

来源之后被修改过，引用会标出「证据引用的源文件版本已变更」，并保留回答当时依据的原文。你始终看得到结论最初建立在什么之上。

## 结构化知识

论证成形时，可以把它明确记下来。Knovum 提供六种知识对象：**观点、证据、问题、决策、概念、实验**，也可以在「管理知识类型」里自定义。对象之间用有含义的关系连接，例如「支持」「反证」「解答」「依赖」「派生自」。

「知识检查」会扫描整个空间，指出需要处理的地方：缺少支持的观点、已确认却存在反证的观点、没有来源的证据，以及来源已经变化的引用。

## 本地模型

转录、语义搜索、去背景、图片放大、说话人识别等功能使用电脑上的本地模型。模型在你第一次用到某个功能时才下载，之后离线也能运行。

## 任务

下载模型、转录、生成内容这类耗时的工作会出现在「任务」面板里，显示进度。任务运行时你可以继续做别的事，也可以在这里取消。
