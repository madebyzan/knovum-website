## 留在你电脑上的

- 所有空间、画布结构和你写下的内容。
- 导入文件的副本，以及从中提取的文字。
- 搜索索引，包括语义搜索的向量索引。
- 本地模型完成的工作：转录、说话人识别、语义搜索、去背景、图片放大、修补、语音合成、人声分离。

这些功能在模型下载完成后完全离线运行。

## 什么时候会联网

| 你做的事               | 发给谁                    | 发送什么                         |
| ---------------------- | ------------------------- | -------------------------------- |
| 添加网页、刷新网页     | 那个网站                  | 一次普通的页面请求               |
| 第一次使用本地功能     | 模型下载源                | 下载请求，下载后校验文件         |
| 用 AI 服务商提问或生成 | 你为这次操作选择的服务商  | 这次操作需要的内容，例如所选资料 |
| 使用桌面 Agent         | 那个 Agent 及它配置的服务 | 由 Agent 自己的设置决定          |
| 使用 MCP 连接          | 那个 MCP 服务             | 你允许调用的工具参数             |
| 检查更新               | Knovum 的发布服务         | 版本检查请求                     |

Knovum 不会在你不知情时把资料发给某个服务商，也不会在一个服务商失败后悄悄换另一个重试。

## 密钥与凭据

API Key、连接令牌等敏感信息保存在本机独立的凭据库里，不写进空间内容，也不写进日志。画布上的「凭据」节点只保存名称和配置状态，复制节点不会复制其中的密钥。

空间包和资料库备份都不包含凭据。从备份恢复后，需要重新填写服务商和连接的密钥。

## 你需要留意的

- **本地不等于加密**：资料保存在你的电脑上，Knovum 不另行加密。请使用系统的磁盘加密（macOS 的 FileVault、Windows 的 BitLocker）保护电脑和导出的文件。
- **「本地」端点不一定在本机**：把远程服务器上的 Ollama 命名为「本地」，它仍然是远程服务。
- **便签里的密钥就是普通内容**：会被搜索，也会随空间一起导出。密钥只填在凭据字段里。
- **分享之前看一眼**：导出的空间包、文档和 JSON 里包含什么，分享前先检查。
