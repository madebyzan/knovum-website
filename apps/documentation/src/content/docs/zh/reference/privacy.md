## 留在本地的内容

Space 结构、托管资产、抽取文本和搜索索引保存在电脑上。关键词搜索、向量推理和普通语音转写在所需资源安装完成后于本地运行。

本地保存不自动等于加密保存。使用合适的系统安全措施和磁盘加密保护电脑及导出包。

## 网络边界

| 操作               | 网络使用                       |
| ------------------ | ------------------------------ |
| 保存网站           | 请求指定站点及可用预览资源     |
| 准备本地模型或工具 | 下载经验证资源                 |
| 服务商生成或理解   | 向选定执行器发送操作所需上下文 |
| 外部 Agent         | 使用其自身认证与工具权限       |

Ollama 等本地端点与托管服务不同，但仍应检查端点真实配置。“本地优先”不保证每个已配置执行器都位于本机。

## 凭据

服务商密钥和敏感信息秘密值保存在独立本地凭据数据库。画布内容保存描述及配置状态，而非秘密值。复制凭据对象不会复制其中的秘密。

分享 JSON、文档或 Space 包前检查实际内容。不要将真实密钥写进普通笔记或提示词，它们属于内容，不是受保护的凭据字段。
