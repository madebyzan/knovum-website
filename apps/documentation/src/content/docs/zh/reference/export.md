## 按目的选择

| 想做的事                             | 用什么                   |
| ------------------------------------ | ------------------------ |
| 把一篇文档、一张图、一段视频交给别人 | 资源导出                 |
| 把整个空间搬到另一台电脑             | 空间包（`.knovumspace`） |
| 与支持 JSON Canvas 的工具交换画布    | JSON Canvas（`.canvas`） |
| 备份整个资料库                       | [备份与恢复](../backup/) |

## 导出一个资源

选中资源，选「导出」，挑选格式，命名后保存。能选哪些格式取决于资源本身：

| 资源 | 可导出格式                                             |
| ---- | ------------------------------------------------------ |
| 文档 | Markdown、纯文本、HTML、Word、PDF、演示文稿（.pptx）   |
| 图片 | PNG、JPEG、WebP、TIFF                                  |
| 音频 | WAV、MP3、AAC（.m4a）、FLAC                            |
| 视频 | MP4、QuickTime（.mov）、Matroska（.mkv），或只导出音频 |

Markdown 文档也可以直接「导出 Markdown」。图片导出的是应用了编辑之后的结果。

文档转换会保留标题、段落、列表、表格这些内容结构，并按目标格式重新排版，不保证与原始 Office 文件的页码和版式完全一致。需要原样的版式，请用原文件。

## 把空间搬到另一台电脑

1. 在资料库里，从空间的菜单选「导出空间包…」，保存 `.knovumspace` 文件。
2. 在新电脑上安装 Knovum，选「导入空间包…」。
3. 导入后会出现一个新空间。确认内容完整之前，保留原来的空间包文件。

空间包包含这个空间里的全部内容：资源与原文件、画布结构、知识对象与关系、生成记录、引用，以及被语音项目使用的音色。不包含应用设置、凭据和本地模型，这些在新电脑上重新配置即可。

## JSON Canvas

「导出 JSON Canvas…」和「导入 JSON Canvas…」用于和其他支持 JSON Canvas 的工具交换画布布局。它只描述画布上的位置和连线，不是完整的知识备份；`.canvas` 文件引用的资源放在旁边的文件夹里，移动时请一起带上。
