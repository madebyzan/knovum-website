---
title: 备份与恢复资料库
description: 为整个资料库做一份完整备份，需要时原样恢复。
---

资料库备份保存的是 Knovum 的全部数据，适合定期留底，或在重装系统前做保险。只想把一个空间搬走，用[空间包](../export/)更合适。

## 备份包含什么

| 包含                 | 不包含               |
| -------------------- | -------------------- |
| 所有空间及其中的资源 | 服务商密钥和连接凭据 |
| 用量历史与偏好设置   | 已下载的本地模型     |
| 音色与语音资源       | 运行时、缓存和日志   |
| 已安装的扩展         |                      |

## 创建备份

1. 先完成或取消「任务」面板里正在运行的任务。有任务在运行时，备份无法开始。
2. 打开设置，进入「数据与归档 → 数据」，点「创建备份」，选择保存位置。
3. 确认「重启知生知以创建此备份？」。Knovum 会保存未保存的修改，重启进入维护模式，生成备份后继续启动。
4. 看到「备份已创建」即完成。把备份文件存到 Knovum 数据目录以外的地方，例如外接硬盘。

## 恢复备份

:::caution[恢复会替换当前的全部数据]
恢复不是合并：当前资料库会被备份里的内容整体替换。恢复前，把当前需要保留的空间先导出为空间包。
:::

1. 进入「数据与归档 → 数据」，点「恢复备份」，选择备份文件。
2. 阅读确认信息，确认重启。Knovum 会先完整校验备份，校验通过才替换数据；恢复失败时会自动回滚到原来的状态。
3. 恢复完成后，重新填写服务商和连接的密钥，本地模型在第一次使用时重新下载。

备份需要与当前版本的 Knovum 匹配，并恢复到原来的数据位置。要在不同的电脑或安装之间移动内容，请用空间包。
