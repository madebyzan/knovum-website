## 入门

### Knovum 是做什么的？

把录音、网页、文档和笔记放进一个空间，在本机转录和搜索，再向这些资料提问。每个回答都附带来源，点开就是原文，你可以逐条核对。

### 和笔记软件、聊天机器人有什么不同？

笔记软件帮你存放资料，聊天机器人给你一个回答。Knovum 把两者接在一起：回答只来自你自己的资料，每个判断都标明出处。

### 收费吗？

个人非商业使用免费。源代码依据 Knovum 个人非商业许可 1.0 公开在 GitHub 上。

### 支持哪些系统？

macOS 14 及以上，Apple 芯片和 Intel 芯片都支持；Windows 10 版本 2004 及以上的 64 位版本。详见[安装 Knovum](../../getting-started/installation/)。

### 需要独立显卡吗？

不需要，普通电脑就能运行核心功能。Apple 芯片的 Mac 会用 Metal 加速转录和语义搜索。音色克隆与设计至少需要 32 GiB 内存，详见[管理本地模型](../../guides/local-models/)。

## 隐私与网络

### 我的资料存在哪里？

在你的电脑上。资料库、导入文件的副本和搜索索引都在本地。详见[隐私与 AI 边界](../privacy/)。

### 可以离线使用吗？

模型下载完成后，编辑、关键词搜索、语义搜索、转录和本地图片处理都可以离线进行。添加网页、第一次下载模型和使用云端 AI 需要联网。

### 会把什么发给 AI 服务商？

只发送你这次操作需要的内容，例如提问时添加的资料，并且只发给你为这次操作选择的服务商。

## AI 与模型

### 必须有 API Key 吗？

整理、搜索和转录都不需要。回答问题、生成文档、图片和视频时，需要 AI 服务商或桌面 Agent。详见[配置 AI 服务商](../../guides/providers/)。

### 能接入哪些服务商？

OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问、智谱、Moonshot（Kimi）、豆包等十七家云服务，以及任意 OpenAI 兼容接口和本地运行的 Ollama。

### 已经在用 Claude Code 或 Codex，能直接用吗？

能。在设置里启用它，就能在对话和创作里选它，它用的是自己的账号。详见[使用桌面 Agent](../../guides/agents/)。

### 为什么第一次转录比较慢？

第一次用到时需要下载并校验语音识别模型，「任务」面板会显示进度。之后的转录会直接开始。

## 文件与内容

### 可以导入哪些资料？

网页、Markdown、PDF、Word、PowerPoint、Excel、图片、音频、视频和代码，单个文件最大 8 GiB。压缩包按普通文件保存，不会解压。详见[收集资料](../../guides/capture/)。

### 修改了电脑上的原文件，Knovum 会同步吗？

不会。Knovum 保存的是导入时的副本。原文件有了新版本，再导入一次即可。

### 能转录多种语言混杂的录音吗？

每段录音按开头识别出的语言转录。中途换了语言的部分，请对照录音核对。

## 迁移与保存

### 换电脑怎么办？

把需要的空间「导出空间包…」，在新电脑上「导入空间包…」。也可以用资料库备份整体迁移，条件见[备份与恢复资料库](../backup/)。另见[导出与迁移](../export/)。
