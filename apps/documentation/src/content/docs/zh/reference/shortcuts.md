---
title: 键盘快捷键
description: Knovum 的全部快捷键，按场景分组。
---

下表中的 <kbd>⌘/Ctrl</kbd> 在 Mac 上是 <kbd>⌘</kbd>，在 Windows 上是 <kbd>Ctrl</kbd>。在应用里按 <kbd>⌘/Ctrl</kbd> + <kbd>/</kbd> 可以随时查看并搜索快捷键。

## 通用

| 按键                                                | 操作             |
| --------------------------------------------------- | ---------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>K</kbd>                    | 命令面板         |
| <kbd>⌘/Ctrl</kbd> + <kbd>/</kbd>                    | 快捷键列表       |
| <kbd>⌘/Ctrl</kbd> + <kbd>,</kbd>                    | 设置             |
| <kbd>⌘/Ctrl</kbd> + <kbd>B</kbd>                    | 显示或隐藏侧边栏 |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> | 显示或隐藏右侧栏 |

## 空间与标签页

| 按键                                                | 操作                 |
| --------------------------------------------------- | -------------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>T</kbd>                    | 新建空间             |
| <kbd>⌘/Ctrl</kbd> + <kbd>W</kbd>                    | 关闭标签页           |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd> | 重新打开关闭的标签页 |
| <kbd>⌘/Ctrl</kbd> + <kbd>1</kbd>–<kbd>9</kbd>       | 切换到第 N 个标签页  |
| <kbd>Ctrl</kbd> + <kbd>Tab</kbd>                    | 下一个标签页         |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd>        | 后退 / 前进          |

## 查找与提问

| 按键                                                | 操作               |
| --------------------------------------------------- | ------------------ |
| <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd>                    | 在当前空间查找     |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | 搜索所有空间       |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | 大纲               |
| <kbd>⌘/Ctrl</kbd> + <kbd>Enter</kbd>                | 就选中内容发起问答 |

## 画布工具

输入文字时，这些单键会让给文字编辑，不会切换工具。

| 按键         | 操作     |
| ------------ | -------- |
| <kbd>V</kbd> | 选择     |
| <kbd>H</kbd> | 平移画布 |
| <kbd>N</kbd> | 新建便签 |
| <kbd>T</kbd> | 文字     |
| <kbd>S</kbd> | 绘制分区 |

按住 <kbd>空格</kbd> 拖动，或按住鼠标中键拖动，也可以平移画布。

## 画布编辑

| 按键                                                           | 操作               |
| -------------------------------------------------------------- | ------------------ |
| <kbd>⌘/Ctrl</kbd> + <kbd>Z</kbd>                               | 撤销               |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd>            | 重做               |
| <kbd>⌘/Ctrl</kbd> + <kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | 复制 / 剪切 / 粘贴 |
| <kbd>⌘/Ctrl</kbd> + <kbd>D</kbd>                               | 创建副本           |
| <kbd>⌘/Ctrl</kbd> + <kbd>A</kbd>                               | 全选               |
| <kbd>Delete</kbd>（Mac 上为 <kbd>Backspace</kbd>）             | 删除选中项         |
| <kbd>F2</kbd>                                                  | 重命名             |
| <kbd>⌘/Ctrl</kbd> + <kbd>G</kbd>                               | 编组选中项         |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd>            | 取消编组           |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd>            | 锁定或解锁选中项   |
| 方向键                                                         | 微移选中项         |
| <kbd>Shift</kbd> + 方向键                                      | 移动 10px          |
| <kbd>Esc</kbd>                                                 | 取消画布操作       |

## 缩放与场景

| 按键                                         | 操作                |
| -------------------------------------------- | ------------------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>=</kbd>             | 放大                |
| <kbd>⌘/Ctrl</kbd> + <kbd>-</kbd>             | 缩小                |
| <kbd>⌘/Ctrl</kbd> + <kbd>0</kbd>             | 重置缩放            |
| <kbd>Shift</kbd> + <kbd>1</kbd>              | 缩放到选中项        |
| <kbd>Shift</kbd> + <kbd>2</kbd>              | 缩放以适应内容      |
| <kbd>Alt</kbd> + <kbd>[</kbd> / <kbd>]</kbd> | 上一个 / 下一个场景 |

## 文档编辑器

| 按键                                                | 操作     |
| --------------------------------------------------- | -------- |
| <kbd>⌘/Ctrl</kbd> + <kbd>S</kbd>                    | 保存     |
| <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd>                    | 查找文本 |
| <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | 文档大纲 |

## 视频编辑工作台

| 按键                             | 操作                |
| -------------------------------- | ------------------- |
| <kbd>空格</kbd>                  | 播放 / 暂停         |
| <kbd>←</kbd> / <kbd>→</kbd>      | 上一帧 / 下一帧     |
| <kbd>Home</kbd> / <kbd>End</kbd> | 回到开头 / 跳到结尾 |
| <kbd>S</kbd>                     | 分割                |
| <kbd>T</kbd>                     | 添加文字            |
| <kbd>⌘/Ctrl</kbd> + <kbd>D</kbd> | 复制片段            |
| <kbd>Backspace</kbd>             | 删除                |
| <kbd>⌘/Ctrl</kbd> + <kbd>S</kbd> | 保存                |
