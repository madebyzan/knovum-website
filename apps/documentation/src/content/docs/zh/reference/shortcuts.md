## 画布工具

| 按键                       | 操作                   |
| -------------------------- | ---------------------- |
| V                          | 选择                   |
| H                          | 平移                   |
| N                          | 便笺                   |
| T                          | 文本                   |
| F2                         | 重命名选中且已保存对象 |
| 空格 + 拖动 / 鼠标中键拖动 | 平移画布               |

输入文字时单键工具会让位。重命名用 Enter 提交、Escape 取消。文字编辑和画布选择属于不同响应上下文，复制跟随当前焦点，不会始终复制画布节点。

## 安全编辑

每个 Space 保留 100 次撤销历史，新编辑清除重做分支。关闭未保存编辑器时选择保存、放弃或取消，取消会保持打开，保存失败不丢弃草稿。

使用大纲定位揭示所属分组或区段内目标，不要因为当前视图在别处就认为隐藏对象被删除。

文档站搜索快捷键是 Cmd/Ctrl+K，属于这个网站，不代表每个产品入口都使用同一快捷键。
