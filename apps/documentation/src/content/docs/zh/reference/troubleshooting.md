---
title: 排查问题
description: 最常见的问题，按现象查原因，按步骤解决。
---

大多数问题都能在「任务」面板里找到线索：它会显示每项后台工作是在下载、排队、进行中、需要配置，还是失败了。先看一眼那里。

## 功能一直在等待

**现象**：转录、语义搜索或图片处理迟迟没有结果。

1. 打开「任务」面板，看任务的状态。
2. 显示「首次使用需下载 … 本地资源」或「校验完整性中…」：模型正在准备，第一次需要下载，请保持联网，确认磁盘空间充足。
3. 显示「需要配置」：这项功能需要你先选一个模型，按提示进入设置。
4. 显示「失败」：点开查看原因，修正后重试。

## 搜不到资料

1. 先用关键词试一次，排除语义搜索没准备好的情况。
2. 确认文档的文字已经提取：选中资源，在「详情」里看「提取的纯文本」和「文档处理」。
3. 录音和视频要先转录，里面的话才能被搜到。
4. 刚在外部应用里改过的文件，切回 Knovum 稍等片刻，它会重新读取。

## 对话里选不到 Agent，或回答失败

1. 「选择 Agent」里没有 Knovum Agent：在「AI 服务商」里给一个支持工具调用的模型开启「用于内置 Agent」。
2. 提示认证失败：检查 API Key，以及服务商后台是否开通了 API 权限。
3. 提示限流或额度不足：这是服务商一侧的限制，等待或提升额度。
4. 桌面 Agent 失败：先在终端里确认它本身能正常运行并已登录。

## 图片或视频生成失败

文字能用，不代表图片和视频也能用。确认添加了支持「图片生成」或「视频生成」的模型，并在「功能模型」里分配给了「图片创作」「视频创作」。

## 无法删除或移动资源

文档或视频正在某个编辑标签页里打开时，Knovum 会保护它。关闭那个标签页，按提示保存或放弃修改，再删除或移动。

## 导出失败

等资源处理完成再导出，并确认选择的是这个资源支持的格式。复杂的 Office 版式可能无法完整转换，需要原样的版式请使用原文件。

## 安装或启动失败

- 重新从官网或 GitHub 发布页下载安装包，不要为了装上而关闭 Gatekeeper 或 SmartScreen。
- 启动失败时，界面会提供「重新加载界面」和重置选项。重置设置会清除偏好设置和已保存的服务商密钥，你的空间内容会保留。

:::danger[不要手动删除数据文件]
删除 Knovum 的数据目录或数据库文件来「解决」问题，会让你丢失资料。先备份，再寻求帮助。
:::

## 报告问题

在 [GitHub](https://github.com/madebyzan/knovum/issues) 上提交问题时，请写明系统版本、Knovum 版本（「设置 → 关于」）、复现步骤和错误信息。截图前遮住 API Key、私人内容和个人文件路径。
