---
title: 配置 AI 服务商
description: 接入你已有的 AI 账号，添加模型，再为写作、对话、图片等功能分配合适的模型。
---

整理、搜索、转录都不需要 AI 账号。想让 Knovum 回答问题、生成文档和图片，就接入一个你已经在用的服务商。整个过程分三步：添加服务商，添加模型，分配给功能。

:::note[需要准备]
服务商账号和 API Key。网页版聊天订阅通常不包含 API 额度，请在服务商的开发者后台单独开通。
:::

## 支持的服务商

OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问、智谱、Moonshot（Kimi）、豆包、MiniMax、阶跃星辰、硅基流动、可灵、xAI Grok、Mistral、Groq、Together、OpenRouter 和 Ollama。其他服务只要提供 OpenAI 兼容接口，也可以接入。

## 1. 添加服务商

1. 按 <kbd>⌘/Ctrl</kbd> + <kbd>,</kbd> 打开设置，进入「智能能力 → AI 服务商」。
2. 点「添加服务商」，在「模型服务商」里选择你的服务商。
3. 填一个认得出的「连接名称」，例如「OpenAI · 工作账号」。
4. 在「API Key」里粘贴密钥。使用 OpenAI 兼容接口或 Ollama 时，再填写「API Base URL」。
5. 保存。

同一个服务商可以添加多个连接，用来区分不同账号。

## 2. 添加模型

在连接下点「添加模型」：

- **服务商模型标识**：服务商文档里的模型 ID，例如 `deepseek-chat`。
- **模型显示名称**：在 Knovum 里显示的名字。
- **支持的能力**：勾选这个模型实际支持的「文本生成」「视觉理解」「图片生成」「视频生成」。
- **用于内置 Agent**：开启后，这个模型可以驱动对话里的 Knovum Agent。只有支持工具调用的模型才能开启；上下文和输出上限会按模型自动识别。

## 3. 分配给功能

进入「智能能力 → 功能模型」：

- 「全局默认」里的「默认模型」用于所有没有单独设置的功能。
- 在「按功能设置」里，可以为「写作」「智能助手」「视觉理解」「翻译」「图片创作」「视频创作」分别指定模型或 Agent。

例如：日常写作用便宜快速的模型，视觉理解用支持图片的模型，图片创作交给专门的图片模型。

## 用一次真实的操作测试

用一份不敏感的资料，试一下你实际要用的功能。文字回答成功，只说明文字生成可用；图片、视频还要各自试一次，因为它们往往对应不同的模型和权限。

## 费用与用量

调用服务商的模型按服务商的价格计费。在「智能能力 → 使用情况」里可以查看近一年内置 AI 的 Token 用量和活动；只有返回用量信息的服务会被计入。

## 密钥的保存

API Key 保存在本机专用的凭据库里，不会写进空间内容或日志。编辑连接时，密钥框显示「已保存密钥，留空则保持不变」；要删除，点「移除已保存的密钥」。

不要把密钥写进便签或提示词：那样它就成了普通内容，会被搜索、被导出。

## 使用 Ollama 等本地服务

Ollama 运行在你自己的电脑上时，请求不会离开本机。添加时选择 Ollama，确认服务已经启动、「API Base URL」可以访问。注意：把一台远程服务器上的 Ollama 命名为「本地」，它仍然是远程服务。

## 连接失败时

| 现象               | 先检查                                            |
| ------------------ | ------------------------------------------------- |
| 认证失败           | API Key 是否正确、是否已开通 API 权限             |
| 文字能用，图片不行 | 是否添加了图片模型，并勾选了「图片生成」          |
| 对话里选不到 Agent | 是否有模型开启了「用于内置 Agent」                |
| 限流或额度用完     | 服务商后台的额度；Knovum 不会自动换另一个账号重试 |
