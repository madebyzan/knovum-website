## 连接前准备

需要所选服务商账号、相应 API 权限和有效凭据。订阅服务商聊天网站不一定获得 API 使用额度。发送私人内容前，确认计费和数据处理政策。

## 建立连接

1. 打开设置中的 AI 服务商连接入口。
2. 新增连接，从可用目录选择服务商。
3. 填写能辨识账号的名称，按服务商或兼容服务要求设置端点。
4. 在凭据字段填写密钥，不要写进普通笔记，保存连接。
5. 配置可用模型，在提问或创建操作中选择合适执行目标。
6. 用少量非敏感内容测试将要使用的实际操作。

多个连接可以区分账号和端点。自定义 OpenAI 兼容端点不保证支持图片编辑、视频生成或所有请求格式。

## 按操作定位故障

一次文字回答成功只验证该文字操作。图片或视频失败时，分别检查模型能力、端点、权限和凭据。限流或额度耗尽属于服务商侧条件，Knovum 不会悄悄将失败请求转给另一个账号。

修改秘密字段并保存会替换其值，保持不变则保留原值。不要将密钥放进截图或问题报告。

## 本地端点

Ollama 等兼容本地服务需要实际运行，且配置的端点可访问。模型与操作支持由该服务管理，不属于 Knovum 内置本地模型安装器。即使将连接命名为“本地”，远程主机仍是远程服务。
