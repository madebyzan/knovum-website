---
title: 查找资料
description: 用关键词精确查找，用语义搜索按意思查找，在一个空间或所有空间里。
---

Knovum 有两种搜索方式，都在你的电脑上运行。

| 方式         | 适合                                 | 需要什么                 |
| ------------ | ------------------------------------ | ------------------------ |
| **关键词**   | 记得原话、人名、术语                 | 什么都不需要，打开即用   |
| **语义搜索** | 只记得大意，或想找说法不同的相似内容 | 第一次使用时下载本地模型 |

## 在当前空间查找

按 <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd> 打开「查找」，输入关键词。结果涵盖便签、网页、转录文本、文件内容和标签。点一条结果，画布就会定位到它；命中的是录音，结果会标出时间段。

## 在所有空间查找

不记得资料放在哪个空间，按 <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>「搜索所有空间」。

## 按意思搜索

在搜索框里打开「语义搜索」。第一次使用时，Knovum 会下载本地向量模型 Qwen3 Embedding，并为空间里的内容建立索引，「任务」面板会显示「正在建立内容索引」。完成之后，用一句话描述你要找的东西就行，例如「用户抱怨上手太难的地方」。

语义搜索的模型和索引都在本机，不需要 AI 账号，内容也不会发出去。

## 相关内容

选中一个资源，打开「详情」里的「相关内容」，Knovum 会按意思找出当前空间里与它相关的其他资料。它只是建议，不会自动在画布上连线。

## 搜不到时

1. **内容还没处理完**：文档的文字提取、录音的转录完成之前，里面的内容搜不到。看一眼「任务」面板。
2. **刚改过的文件**：在外部应用里改过的文件，Knovum 会在窗口重新获得焦点时重新读取，稍等片刻再搜。
3. **语义搜索没反应**：确认索引已经建好。必要时可以「重建向量检索索引」。

:::note[匹配分数]
语义搜索按相似程度排序。排在前面说明意思相近，不代表内容正确，还是要打开原文看一看。
:::
