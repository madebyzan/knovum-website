---
title: 收集资料
description: 把网页、文档、图片、录音和视频放进空间，并确认 Knovum 读得到里面的内容。
---

资料进了空间，才能被搜索、被引用。这一篇讲怎么把各种资料放进来，以及怎么确认 Knovum 真的读到了内容。

## 三种最快的方式

- **拖进来**：把文件从桌面或访达、资源管理器直接拖到画布上。
- **粘贴**：复制一段文字、一张图片或一个网址，在画布上粘贴。
- **双击**：双击画布空白处，新建一张便签，直接写。

需要更多选项时，打开画布上的「添加内容」。

## 保存网页

在「添加内容」里选「添加网页」，粘贴网址。Knovum 会保存链接，并抓取标题、摘要和可读的正文，之后就能搜索和引用。

抓取失败时链接仍会保留，可以在「详情」里点「刷新网页内容」重试。需要登录才能看的页面，通常抓不到正文。Knovum 保存的是可读正文，不是整站的离线备份，原网址始终保留，方便回去核对。

## 导入文件

选「导入文件…」，或直接拖入。常见格式都能导入：

| 类型                  | 导入后可以做什么                           |
| --------------------- | ------------------------------------------ |
| Markdown              | 直接在 Knovum 里编辑                       |
| PDF、Word、PPT、Excel | 提取文字，用于搜索和引用                   |
| 图片                  | 配置视觉模型后，可识别画面内容和其中的文字 |
| 音频、视频            | 在本机转录成可搜索的文字                   |
| 代码                  | 按行号引用                                 |

导入时，Knovum 会把文件复制一份存进资料库，你电脑上的原文件保持原样。两者之后不会同步：原文件有了新版本，再导入一次即可。

## 确认内容可读

文件导入后，文字提取、转录等处理在后台进行，进度显示在「任务」面板里。选中资源，打开「详情」查看：

- 「提取的纯文本」：Knovum 从文档里读到的文字。
- 「OCR 识别文本」：从图片里识别出的文字。
- 「文档处理」：已经提取了多少页。扫描版 PDF 中只有图片的页面会单独列出。

只有读得到的内容，才能被搜到和引用。提问前先确认这一点，能省掉很多困惑。

## 限制

- 单个文件最大 8 GiB。
- 文字提取的上限是 128 MiB 和 2,000 页 PDF；更大的文件可以导入和打开，但不会完整提取。
- 压缩包按普通文件保存，不会解压，里面的内容也不会被搜索。
- `.env` 这类可能含密钥的文件，不会生成可搜索的文字预览。

## 在外部应用里编辑

选中资源，选「在外部编辑器中打开」。你在外部应用里保存后，Knovum 会在下次启动或窗口重新获得焦点时重新读取内容。
