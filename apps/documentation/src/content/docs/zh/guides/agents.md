## 先检查执行器

设置展示受支持桌面 Agent、安装状态和连接要求。按该 Agent 的帮助链接安装所需可执行程序，完成自身登录后再在 Knovum 启用。检测到安装不证明账号有权限或任务必然成功。

启用后，在兼容对话或创建操作选择它。外部 Agent 不自动继承 Knovum 服务商密钥，使用自己的认证、订阅与配置。

## 提供边界明确的任务

说明预期产物与相关来源范围。检查允许的工具和文件，特别是能修改内容或执行命令的任务。已安装执行器不构成允许访问整台电脑的理由。

关注 Run 或任务状态，不要认为关闭面板就停止持久任务。使用前检查产物与来源记录。失败仍是失败，不授权悄悄换另一个 Agent。

## 扩展按执行器管理

Skills、插件和 MCP 连接通过 Agent 扩展入口管理，可用性取决于执行器支持。为目标 Agent 配置扩展，不假设全部 Agent 共用一个通用扩展目录。
