---
title: 提问与核查引用
description: 让 Agent 只用你给的资料回答，再把每条来源和原文逐一对照。
---

在 Knovum 里提问，回答来自你自己的资料，每个判断都附带来源。你要做的是两件事：给对资料，然后核对引用。

:::note[需要准备]
一个能回答问题的 Agent：在[AI 服务商](../providers/)里添加模型并开启「用于内置 Agent」，或者启用一个[桌面 Agent](../agents/)。
:::

## 1. 选择 Agent

打开「对话」面板，点「选择 Agent」：

- **Knovum Agent**：内置 Agent，使用你开启了「用于内置 Agent」的模型。只有支持工具调用的模型才能开启。
- **桌面 Agent**：这台电脑上已安装并登录的 Agent，使用它们自己的账号和订阅。

列表是空的，点「配置模型与 Agent…」去设置。

## 2. 给它资料

范围越贴近问题，回答越准，核对起来也越省事。点「添加资料」：

- 「引用画布内容」：从当前空间里挑选资源。
- 「添加当前选中」：把画布上选中的内容一次加进来。选中一个分区，就带上了里面的全部资料。
- 「添加本地文件」：临时加一张图片、一份 PDF 或文档，不必先导入空间。图片不超过 10 MiB，其他文件不超过 20 MiB。

一次对话最多 32 项资料。快捷方式：在画布上选中内容，按 <kbd>⌘/Ctrl</kbd> + <kbd>Enter</kbd>「发起问答」。

## 3. 把问题问清楚

好问题会说清楚要什么、怎么交代依据：

> 这三份报告对明年的预算增长判断一致吗？
> 每个判断都附上原文；报告之间有分歧时，分别列出各自的说法。
> 资料里没有提到的，直接说没有。

空白对话里也有三个起点可以直接用：「找资料」「创建文档」「梳理观点」。

Agent 工作时，会显示「执行计划」和每一步操作，结束后可以展开「过程记录」查看它查了什么、读了什么。

## 4. 核对引用

回答下方列出「来源 · N」。每条来源指向确切的位置：PDF 的页码、文档的段落、录音的时间段、代码的行号。

逐条点「定位至来源位置」，问自己一句：**原文真的这么说了吗？** 回答写得再流畅，也只有核对过的部分才算数。对不上的判断，删掉或标为待确认。

:::caution[来源后来被修改过]
引用会标出「证据引用的源文件版本已变更」。它保留的是回答当时依据的原文，不是来源的最新内容。需要基于新版本的判断，重新问一次。
:::

## 5. 留下有用的部分

- **摘录为证据**：把一段核对过的原文变成画布上的证据对象，之后可以连到观点上，见[结构化知识](../knowledge/)。
- **生成的内容**：Agent 创建的文档或图片会直接放进画布，提示「已添加到画布」；点「定位产物」找到它。
- **换个方向**：对某一轮回答不满意，在那条消息上「从这里分支」，原来的对话保持不变。

## 对话扩展

在「对话扩展」里可以为这次对话选择插件、个人技能或 MCP 连接。内置插件包括：

| 插件     | 做什么                                   |
| -------- | ---------------------------------------- |
| 知识整理 | 查阅、整理和发布空间知识，保留来源依据   |
| 证据研究 | 对照资料，形成有据可查的研究与决策简报   |
| 会议纪要 | 从会议转录中整理要点、决策和待办         |
| 文档交付 | 基于资料制作报告，交付所需的文档格式     |
| 学习辅导 | 把空间资料整理为学习指南、练习与复习计划 |

另有 GitHub、Notion、Linear 工作流插件，连接账号后可用。需要访问外部服务时，Knovum 会先弹出「外部操作需要授权」，由你选择「允许」或「拒绝」。详见 [MCP 与扩展](../mcp/)。

## 对话的管理

「新建对话」开始一个新话题；「对话历史」里可以搜索、归档和导出以前的对话。每个空间的对话各自保存。
