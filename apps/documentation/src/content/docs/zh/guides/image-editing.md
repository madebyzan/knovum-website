---
title: 编辑图片
description: 裁剪调色、抠图去背景、放大修补，大部分操作在本机完成，原图始终保留。
---

选中一张图片，就能直接编辑。Knovum 把图片操作分成两类：

- **编辑**：裁剪、旋转、调色，改的是这张图片本身，确认后「应用」。
- **生成**：去背景、放大、修补、抠出对象、新视角、相对深度，会生成一张新图片放在原图旁边，原图不变。

## 裁剪、旋转与调色

- **裁剪**：自由裁剪，或选预设比例「正方形」「快拍」「竖版」「横版」，「锁定裁剪比例」后拖动不会变形。
- **翻转与旋转**：「顺时针旋转」「水平翻转」「垂直翻转」，或输入「旋转角度」。
- **调整**：四组滑块，「光线」（曝光、对比度、高光、阴影、白色、黑色）、「颜色」（饱和度、自然饱和度、色温、色调）、「质感」（锐化、清晰度、颗粒）、「效果」（晕影、柔光、辉光）。

满意后点「应用」，形成一次可撤销的编辑；离开前没有应用，Knovum 会询问「要应用图片更改吗？」。导出时使用的是应用后的结果。

## 在本机完成的操作

这些操作使用本地模型，第一次使用时下载，之后离线也能用，图片不会离开电脑：

| 操作         | 说明                                                             |
| ------------ | ---------------------------------------------------------------- |
| **去背景**   | 自动移除背景，生成透明背景的新图片                               |
| **放大**     | 输出 2K、4K 或 8K 版本，适合放大小图、修复模糊截图               |
| **选择对象** | 点选主体，用「排除点」「框选」「笔刷补充」修正选区，最多六个提示 |
| **抠出对象** | 把选中的对象单独存成一张图                                       |
| **修补**     | 用「橡皮擦」涂抹不想要的部分，「移除并生成」后自动填补           |
| **相对深度** | 生成深度图，近处较亮、远处较暗                                   |

选区只是临时状态，点「抠出对象」或「移除并填补」才会生成新图片。修补支持不超过 1600 万像素、每边不超过 16,384 像素的图片。

## 需要 AI 服务商的操作

- **文字描述修补**：在「橡皮擦」里切到「文字描述」，写下要移除的内容，例如「去掉右下角的水印」。
- **新视角**：拖动调整「主体」或「摄像头」的「旋转」「倾斜」「缩放」，从「广角」到「特写」，生成同一画面的另一个角度。

这两项需要支持图片编辑的模型。普通的文字模型不能编辑图片；没有可用模型时，界面会提示「请检查图片模型与凭据配置」。

## 给图片加评论

用「评论」在图片上标注：「点选评论」「框选区域评论」或「自由绘制评论」。评论可以「添加到对话」，Agent 会拿到标注的位置和内容，适合说「把框出的这块换成蓝色」。

:::note[看结果时留意]
放大和修补是 AI 重建出来的细节，适合展示，不能证明原图里真的有这些内容。深度图表示相对远近，不能用来测量实际距离。
:::
