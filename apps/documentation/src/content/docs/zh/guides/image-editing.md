## 编辑同一图片

选中图片后使用上下文编辑工具。裁剪、旋转、翻转和确定性调整属于原节点的编辑会话，预览后选择应用或取消。应用形成一次历史操作，资源导出使用当前已应用结果。

## 生成独立结果

去背景、放大、修复、智能选区提取和相对深度估计使用本地模型，并创建派生资源。文字描述删除与多角度生成可以使用兼容且明确选择的远程目标。操作决定合法执行目标，普通文字模型不自动成为图片编辑模型。

1. 选中来源和合适操作。
2. 设置所需蒙版、点、矩形或参数。
3. 执行生成，检查准备与执行进度。
4. 检查新资源及其来源关系。

成功派生会自动发布，无需再次点击“添加结果”，原件仍保留。

## 智能选区与深度

包含点、排除点、矩形和画笔补充属于临时选区状态。只选择不会创建资产，提取或修复才会生成。

深度结果为含相对逆深度的 16 位 PNG，越亮表示越近，不是测量距离。保留原始 PNG，将其视作分析数据，不要作为照片调色。目前没有已验证的深度模糊操作。

放大检查细边、头发和修复细节。AI 重建不构成原始内容真实存在的证明。
