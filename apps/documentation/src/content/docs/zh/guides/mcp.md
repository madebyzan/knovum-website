## 连接意味着什么

MCP 为兼容 Agent 暴露工具或资源，不是模型服务商密钥，也不会让未连接 Agent 自动可用。从目标 Agent 的扩展入口开始。

## 配置传输方式

- **本地进程**：设置命令、参数和所需环境值。使用服务器官方安装说明，命令必须能在真实电脑运行。
- **HTTP**：填写服务端点与所需请求头或认证，确认目标 Agent 支持该配置。

命名、保存连接并确认展示的可用状态。在允许修改前，用无害只读工具测试。本地服务器运行软件，远程服务器可收到工具参数，两种边界都不自动安全。

## Skills 与插件

检查扩展安装什么、由哪个执行器拥有。指令会影响 Agent 行为，熟悉名称不代表可信。敏感值保存在对应配置字段，不放进公开文档或问题截图。

排障时区分缺少可执行程序、端点错误、认证不可用与执行器不支持配置。服务器示例含他人路径或凭据时，不要原样粘贴。
