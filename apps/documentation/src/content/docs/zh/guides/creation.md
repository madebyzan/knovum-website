---
title: 用选中项创建
description: 选中资料，说清楚要什么，生成文档、图片或视频，并保留它依据了哪些来源。
---

在 Knovum 里创作，素材就是你选中的资料。生成的结果是一个新资源，它会记住自己用了哪些来源；原始资料不会被改动。

## 生成文档、图片或视频

1. 在画布上选中作为素材的资料：笔记、网页、转录过的录音、图片都可以，最多 32 个。
2. 选「用选中项创建」。
3. 在「创建」里选「文档」「图片」或「视频」。
4. 在「你的需求」里说清楚要什么，例如「写一份两页的结论备忘，按原因分节，每节附上原文」。
5. 图片和视频可以设置「画面比例」，视频还可以设置「时长」。点「创建」。

进度显示在「任务」面板里，完成后结果直接出现在画布上，挨着它的素材。

:::note[需要什么]
文档需要支持文本生成的模型，图片和视频需要支持图片生成、视频生成的模型。在「设置 → 功能模型」的「按功能设置」里，可以为「图片创作」「视频创作」分别指定模型。
:::

## 一步完成的操作

选中某个资源时，Knovum 会给出适合它的操作，常见的有：

| 选中       | 可以做                                                   |
| ---------- | -------------------------------------------------------- |
| 资料、笔记 | 生成文档、编写视频脚本、编写社交文案                     |
| 会议录音   | 整理会议摘要                                             |
| 图片       | 去背景、拆分图层、放大、修补、抠出对象、新视角、相对深度 |
| 视频       | 添加字幕                                                 |

去背景、放大、修补、抠出对象、相对深度这些图片操作使用本地模型，在电脑上完成，见[编辑图片](../image-editing/)。

## 结果从哪里来

选中生成的资源，在「详情」里能看到：

- **来源知识**：生成时用了哪些资料、哪个版本。
- **引用 · N**：文档里每个判断对应的原文。

之后来源被修改，结果不会被悄悄改写，而是提示「创建此内容后，部分来源已发生变化」。是否根据新版本重新生成，由你决定。

生成的内容和其他资料一样需要核对：图片里改变的细节、文档里的每个判断，都对照原文看一眼。

## 用桌面 Agent 创作

需要更复杂的成品，例如一套演示文稿或一个网页，可以交给桌面 Agent：

1. 选「使用 Agent 创作」，描述希望 Agent 创建的内容，按需「添加参考文件」。当前空间的知识会通过 MCP 自动连接给 Agent。
2. 点「运行 Agent」。
3. 完成后检查生成的文件，选「导入 N 个文件」放进空间，或「丢弃结果」。

## 失败时

生成失败会留在画布上，标记「创建失败」，可以「移除失败项」后重试。Knovum 不会在失败后悄悄换一个账号或服务商重试。
