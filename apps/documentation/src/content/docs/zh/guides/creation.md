title: 从选中创建
description: 生成新资源，同时保留使用的输入记录。
---

## 先选输入，再选意图

选中相关来源后使用“从选中创建”。意图包括生成文档、图片、视频、去背景、拆分图层和添加字幕。实际可用项取决于所选资源和兼容执行目标。

支持文生图不等于支持图像编辑。使用操作入口给出的兼容选择，不要假设每个已配置模型都支持所有意图。

## 本地与服务商执行

本地图像操作按需准备所需模型。图片和视频生成使用兼容服务商，部分 Agent 任务使用明确选择的外部执行器。失败不会授权应用悄悄切换到另一账号或服务商。

在任务中心或 Run 入口检查准备、执行、审查和失败状态。取消不代表已经提交的所有输出必然消失，应检查最终状态。

## 检查派生记录

派生产物是独立资源，记录动作、输入身份与修订、执行身份及输出。来源后来变化不会悄悄重写产物。

将结果与原件比较，特别是生成陈述或改变的图像细节。导出产物只是将文件写到 Knovum 外部，不是再次派生。
