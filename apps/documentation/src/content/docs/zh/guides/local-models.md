---
title: 管理本地模型
description: 哪些功能用本地模型、什么时候下载、怎样为你的电脑选合适的版本。
---

转录、语义搜索、图片处理和语音合成都使用你电脑上的本地模型。它们不随安装一次性下载，而是在你第一次用到某个功能时才准备好。下载之后，这些功能离线也能用，资料不会离开本机。

## 在哪里管理

按 <kbd>⌘/Ctrl</kbd> + <kbd>,</kbd> 打开设置，进入「智能能力 → 本地模型」。模型按「知识检索」「音频与语音」「图片」分组，每个模型都标出用途、文件大小和下载状态。可以搜索模型或功能，也可以筛选「已下载」「未下载」。

| 功能       | 模型                                        |
| ---------- | ------------------------------------------- |
| 向量检索   | Qwen3 Embedding（固定，用于现有知识索引）   |
| 音视频转录 | Whisper Tiny、Small、Large V3               |
| 转录对齐   | Qwen3 Aligner 及其量化版，单次最长五分钟    |
| 说话人识别 | Sherpa 轻量版与完整精度版                   |
| 人声分离   | Spleeter 轻量版与完整精度版，音频最长十分钟 |
| 语音合成   | MOSS-TTS-Nano、VoxCPM2 及其量化版           |
| 背景移除   | U²-Net 轻量版与完整版                       |
| 图片放大   | Real-ESRGAN 轻量版与完整版                  |
| 选区修补   | MI-GAN                                      |
| 智能选区   | EfficientSAM Ti、S                          |
| 相对深度   | Depth Anything V2 Small 及其量化版          |

## 选择默认模型

同一功能有多个模型时，点「设为默认」，它就成为「新操作的默认模型」。一般来说，轻量版更快、占用更少，完整版更准确、处理更久。

更换默认模型只影响之后的操作。排队中的任务、已经生成的结果、已有的语音项目都保持原来的选择。

## 下载与移除

- 第一次使用某个功能时，所需模型会自动下载，进度显示在「任务」面板里。下载后还会校验文件，校验通过才能使用。
- 想提前准备，在列表里点「下载」。
- 不常用的模型可以「移除」，释放磁盘空间。已经生成的内容会保留，下次使用时再重新下载。
- 显示「文件校验失败，需要重新下载」时，点「重新下载」即可。不要手动替换模型文件。

## 对电脑的要求

- 核心功能不需要独立显卡。Apple 芯片的 Mac 会用 Metal 加速转录和向量检索，其他电脑使用 CPU。
- VoxCPM2 的音色克隆与设计至少需要 32 GiB 内存。内存不够时，可以改用 MOSS-TTS-Nano。
- 同时运行多个大任务会更慢。资源不足时，先等其他重任务完成，或换用轻量模型。

## 换电脑时

模型不包含在空间包和资料库备份里。在新电脑上第一次用到时，会重新下载。
