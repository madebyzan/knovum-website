---
title: 整理空间
description: 用分区、组合、标签和场景，让一张大画布始终找得到东西。
---

空间里的资料多起来以后，靠的不是记忆，而是结构。Knovum 提供几种互不重叠的工具，各管一件事。

## 选对工具

| 工具         | 适合做什么                                   | 怎么用                                                |
| ------------ | -------------------------------------------- | ----------------------------------------------------- |
| **分区**     | 给画布划出有名字的区域，例如「证据」「待读」 | 按 <kbd>S</kbd>「绘制分区」，或选中内容后「创建分区」 |
| **组合**     | 把几个对象绑在一起移动                       | 选中后 <kbd>⌘/Ctrl</kbd> + <kbd>G</kbd>               |
| **标签**     | 跨位置标记同一类内容，之后按标签筛选         | 在「标签」里「添加标签」                              |
| **场景**     | 记住一个视口，之后一键回到那里               | 在「场景」里「保存当前场景」                          |
| **空间入口** | 画布上通往另一个空间的入口                   | 「新建空间入口」                                      |

分区可以折叠，也可以「适应分区内容」自动调整大小；把对象拖进或拖出分区即可改变归属。「仅移除分区」会删掉分区本身，里面的内容留在原处。

## 排列

- 选中多个对象，用「左对齐」「水平居中」「水平等距」等让它们整齐。
- 「自动布局（横向）」和「自动布局（纵向）」一次排好一组内容。
- 不想被误碰的内容，按 <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd> 锁定。

## 找到任何东西

- **大纲**：按 <kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> 打开。点任意一项，画布就会定位过去，所在的分区也会自动展开。
- **查找**：按 <kbd>⌘/Ctrl</kbd> + <kbd>F</kbd> 搜索当前空间。
- **缩放**：<kbd>Shift</kbd> + <kbd>1</kbd> 缩放到选中项，<kbd>Shift</kbd> + <kbd>2</kbd> 缩放到全部内容。
- **聚焦**：选中一部分内容后「聚焦选中项」，画布上只留下它们，按 <kbd>Esc</kbd> 退出。

## 多个空间之间

- 选中内容，用「移动至空间」挪到另一个空间。
- 常用的空间可以「收藏空间」，资料库里的「收藏」和「最近打开」能更快找到它。
- 每个空间在顶部以标签页打开，<kbd>Ctrl</kbd> + <kbd>Tab</kbd> 切换，<kbd>⌘/Ctrl</kbd> + <kbd>W</kbd> 关闭。

## 撤销、归档与删除

每个空间保留最近 100 次编辑，<kbd>⌘/Ctrl</kbd> + <kbd>Z</kbd> 撤销，<kbd>⌘/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> 重做。

暂时用不到的空间，选「归档空间」，它会离开资料库，但内容完整保留。在「设置 → 已归档空间」里可以「恢复空间」，也可以「永久删除」。永久删除无法撤销。

:::note[删除时提示资源正在使用]
文档、视频正在某个标签页里编辑时，Knovum 会保护它，不让它被删除或移到别的空间。先关闭那个标签页，按提示保存或放弃修改，再删除。
:::
