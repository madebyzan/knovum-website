## 按目的选择

| 目的                       | 方式                  |
| -------------------------- | --------------------- |
| 转移完整 Space             | `.knovumspace` 包     |
| 交付一篇文档或一个媒体资源 | 资源导出              |
| 与兼容工具交换画布结构     | JSON Canvas `.canvas` |

## Space 包

从 Space 上下文菜单导出包，通过资料库工具栏导入后会创建新 Space 并重映射身份。包包含活跃内容、托管资产、关系、派生和引用，不包含为撤销保留的软删除内容。

只接受当前包格式。确认导入 Space 内容完整前，保留原始归档。Space 包可迁移，但不是完整应用设置或凭据备份，整库备份使用设置中的独立备份操作。

## 资源导出

选中资源，选择入口实际提供的格式，再在保存对话框命名目标。可用格式取决于实际内容。图片导出已应用的编辑；音频支持 WAV、MP3、M4A、FLAC；视频可以导出视频容器或只导出声音。

文档转换保留受支持语义内容并重新排版，不承诺原始 Office 页码与版式。需要高保真布局时，在专业应用中使用原文件。扫描 PDF 导出不会自动触发 OCR 或 AI 服务。

## JSON Canvas

JSON Canvas 用于画布视觉交换，不是完整知识备份。`.canvas` 文件的相对资源引用依赖伴随资源目录，应一起保留。
