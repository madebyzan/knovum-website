---
title: 语音与有声书
description: 在本机用预设、克隆或设计出的音色朗读文稿，生成有声书和配音。
---

Knovum 的语音合成在你的电脑上运行。你可以用预设音色，也可以用一段录音克隆音色，或者用文字描述设计一个新音色，然后把文稿生成语音或整本有声书。

## 准备音色

音色在「设置 → 音色管理」里统一管理，所有空间都能使用。点「添加音色」，选择「音色来源」：

| 来源             | 怎么做                                               |
| ---------------- | ---------------------------------------------------- |
| **预设音色**     | 直接从内置音色中挑选                                 |
| **参考音频克隆** | 选一段 5–30 秒、清晰的单人语音，Knovum 学习这个声音  |
| **设计音色**     | 描述声音特点、表达方式、年龄感和语气，生成一个新声音 |

克隆时，可以填写「参考音频文本（可选）」并确认「文本与录音内容一致」，效果会更稳定。

保存之前必须完整试听一次候选音色。试听文本默认包含日期和数字，正好用来检查发音是否清晰、节奏是否平稳。

:::caution[只使用你有权使用的声音]
克隆他人的声音前，先取得对方的同意。
:::

### 语音模型

| 模型           | 特点                                                       |
| -------------- | ---------------------------------------------------------- |
| MOSS-TTS-Nano  | 轻量中英文，支持预设音色和参考音频克隆；只用 CPU，正常语速 |
| VoxCPM2        | 支持音色克隆与设计，完整精度；至少需要 32 GiB 内存         |
| VoxCPM2 量化版 | 下载和磁盘占用更小，仍至少需要 32 GiB 内存                 |

第一次使用会自动下载所选模型，进度在「任务」面板里。

### 音色的版本

修改音色时用「新建版本」，旧版本保留在「版本历史」里。已有的项目固定使用当时选择的版本，不会因为你修改了音色而改变。不再使用的音色可以归档；已归档且没有被任何项目引用的音色，才能永久删除。

## 把文稿变成语音

选中一个文本或 Markdown 资源，选「生成语音」。在项目里检查「稿件」，为它选择音色，「试听」一段，满意后生成。

## 制作有声书

1. 选中文稿，新建「有声书」项目，或「导入节点文稿」。
2. 在「书籍信息」里填写书名、作者、朗读者和封面。
3. 按章节整理内容：「添加章节」「添加段落」，上下移动调整顺序。
4. 在「角色音色」里为每个角色选择音色，未指定的段落使用「旁白」。
5. 打开「发音词典」，为人名和专有名词填写准确的读法。
6. 设置「段落停顿（毫秒）」和「章节停顿（毫秒）」。需要特别的语气时，填写「演绎提示」。
7. 在「输出设置」里选择格式、采样率和响度。要嵌入封面，请使用 MP3 或 M4B。
8. 先试听代表性的段落，尤其是有人名和数字的地方，再「生成有声书」。

生成在后台进行，可以在「任务」面板里查看进度或取消。

## 检查成品

用「检查音频信号」扫描生成的音频，它会标出静音、音量偏低或偏高、接近满幅的峰值。这些只是需要复核的位置：刻意的停顿也可能被标出来，它也不评价音色是否自然。最终以你完整听一遍为准。
