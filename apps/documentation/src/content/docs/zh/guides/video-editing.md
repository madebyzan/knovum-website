title: 编辑视频
description: 建立时间线、保存项目，并渲染独立视频。
---

## 打开与编排

在视频资源上打开编辑操作。项目从来源片段、尺寸及可用实测帧率开始，包含视频轨、音频轨、文字叠加、转场和输出设置。

调整源入点与出点，在时间线上排列片段，使用可用的变换、不透明度、片段音量及淡入淡出。文字叠加拥有明确时间范围与样式，检查转场连接正确片段，而不是遮盖缺失区间。

## 保存不等于渲染

保存保留可编辑项目，渲染创建带来源关系的新视频，不覆盖原文件。明确选择输出尺寸与帧率，渲染前预览时间、比例、文字位置与声音。

离开未保存的文档、视频或语音编辑会话时，可以保存、放弃或取消。保存失败保留草稿。资源被编辑标签页使用时，先处理会话，才能删除或跨 Space 移动。

## 字幕与配音

独立“添加字幕”操作将当前转写提示烧录到新视频；没有转写时先进行本地识别。原件不变，普通识别不需要 API 密钥。

翻译声音或对话使用专门配音项目，不要假设视频编辑器自动翻译。交付前检查结果声音和每个字幕边界。
