---
title: 编辑视频
description: 在时间线上剪辑、加文字和转场，渲染成新视频，原片保持不变。
---

选中一个视频，点「编辑视频」，打开「视频编辑工作台」。剪辑的结果保存为一个可以继续编辑的工程；渲染时生成一个新视频，原视频不会被改动。

## 工作台

- **资源库**：「素材」「文字」「转场」。「导入素材」可以加入视频、图片或音频。
- **画面**：预览窗口，可以放大、缩小或「适配窗口」。
- **时间线**：「视频」「音频」「文字」三类轨道。
- **编辑面板**：所选片段的设置。

## 剪辑片段

把素材拖到时间线上，选中片段后：

| 操作             | 方法                                 |
| ---------------- | ------------------------------------ |
| 分割             | 把播放头移到位置，按 <kbd>S</kbd>    |
| 修剪             | 拖动片段两端，或填写「入点」「出点」 |
| 复制片段         | <kbd>⌘/Ctrl</kbd> + <kbd>D</kbd>     |
| 删除             | <kbd>Backspace</kbd>                 |
| 消除空隙         | 让后面的片段向前贴紧                 |
| 调音量与淡入淡出 | 「音量」「淡入（秒）」「淡出（秒）」 |

「画面适配」决定片段怎样放进画幅：「完整显示」或「填满画幅」，还可以调整「缩放」「旋转」「不透明度」。

## 文字与转场

- **文字**：按 <kbd>T</kbd>「添加文字」。可以选「预设样式」（简洁、描边、阴影、底框），设置字体、字重、字号和颜色；在画面上直接拖动文字摆放位置。
- **转场**：从「转场」里把叠化、黑场过渡、白场过渡、擦除或滑动拖到两个片段之间，设置「时长（秒）」。转场会让相邻片段重叠，工程总时长随之变短。

## 预览与快捷键

| 按键                             | 操作                |
| -------------------------------- | ------------------- |
| <kbd>空格</kbd>                  | 播放 / 暂停         |
| <kbd>←</kbd> / <kbd>→</kbd>      | 上一帧 / 下一帧     |
| <kbd>Home</kbd> / <kbd>End</kbd> | 回到开头 / 跳到结尾 |
| <kbd>⌘/Ctrl</kbd> + <kbd>S</kbd> | 保存工程            |
| <kbd>⌘/Ctrl</kbd> + <kbd>Z</kbd> | 撤销                |

## 渲染

1. 在「输出设置」里选择「画幅与分辨率」「帧率」和「背景色」。
2. 预览一遍：时间、比例、文字位置和声音。
3. 点「渲染视频」，进度显示在「任务」面板里。

渲染完成后，新视频出现在画布上，与原视频保持来源关系。

:::note[保存与渲染是两件事]
<kbd>⌘/Ctrl</kbd> + <kbd>S</kbd> 保存的是可以继续编辑的工程，渲染才会生成视频文件。关闭工作台前没有保存，Knovum 会询问「保存视频修改？」。
:::

## 字幕与配音

- 想给视频加字幕，不必进剪辑：选中视频，用「添加字幕」。没有转录时会先在本机识别，然后生成一个带字幕的新视频。
- 想把视频配成另一种语言，使用[配音与声音分离](../dubbing/)。
