## Choose by purpose

| Purpose                                           | Use                    |
| ------------------------------------------------- | ---------------------- |
| Transfer a complete Space                         | `.knovumspace` package |
| Deliver one document or media resource            | Resource export        |
| Exchange canvas arrangement with compatible tools | JSON Canvas `.canvas`  |

## Space packages

Use the Space context menu to export a package. Import through the library toolbar creates a new Space and remaps identities. Packages preserve active content, managed assets, relations, derivations and citations; they do not include soft-deleted content retained for undo.

Only the current package format is accepted. Keep the original archive until you have opened and checked the imported Space. A package is portable, but it is not a full application settings/credentials backup. For a whole-library backup, use the separate Settings backup operation.

## Resource export

Select a resource, choose an offered format, then name the destination in the save dialog. The list is based on the content actually available. Images export the currently applied edits. Audio offers WAV/MP3/M4A/FLAC; videos can export a video container or just audio.

Document conversions preserve supported semantic content and reflow it. They do not promise original Office pagination or layout. Use the original file in its professional application when layout fidelity matters. Scanned PDF export does not automatically invoke OCR or an AI provider.

## JSON Canvas

Use JSON Canvas for visual interchange, not as a complete knowledge backup. Preserve any companion resource directory with the `.canvas` file; relative resource references depend on it.
