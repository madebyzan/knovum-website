---
title: Ask with citations
description: Bound the question, select an executor, and verify evidence.
---

## Set the scope first

Ask against a deliberate set of sources, a Section, a Space or an available all-Spaces scope. Smaller, relevant scope makes the evidence easier to audit. Tell the executor what you want to know and request uncertainty to be stated when sources disagree.

Generation needs an available configured execution target. An external Agent may use its own authentication; a provider-backed operation uses the selected connection. Local search readiness does not imply a generative executor is configured.

## Read the evidence, not just the answer

Citations can point to a recording time range, PDF page, note heading/character range or code lines. Follow the citation and compare the quote with the claim being made.

- **Current:** the citation still refers to matching live knowledge.
- **Detached:** an immutable historical quote/location remains after its source changes or leaves scope.

Detached does not mean fabricated, but it is not a live citation to the replacement content. All-Spaces conversation evidence from other Spaces is stored as historical snapshots rather than creating cross-Space ownership.

## Handle disagreement

Keep competing passages visible. Record a claim and supporting or contradicting evidence instead of treating a generated answer as the final authority. If the relevant source is unavailable, state that gap and acquire it before concluding.
