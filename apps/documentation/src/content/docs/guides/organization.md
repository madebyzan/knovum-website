## Four different tools

| Tool       | Use it for                                                     | What it does not do            |
| ---------- | -------------------------------------------------------------- | ------------------------------ |
| Group      | Move and manipulate related content as a unit; groups can nest | Replace semantic tags          |
| Section    | Define a named spatial region with explicit membership         | Form a nested folder tree      |
| Tag        | Describe meaning independently of position                     | Move content                   |
| Saved view | Return to a viewport, focus and filters                        | Duplicate or own the knowledge |

A Portal navigates to another target; it is not a second copy of that target. Relations and provenance belong to a Space, not to a cross-Space graph.

## Navigate without losing context

Use the sidebar Outline to find content. Its Locate action enters the containing Group and expands the containing Section. Rename a selected persisted object with **F2**; Enter commits and Escape cancels.

The canvas tools are Select (**V**), Pan (**H**), Note (**N**) and Text (**T**). Space-drag or middle-button drag pans the canvas. These shortcuts yield while you are typing.

## Undo and lifecycle

Each Space retains the last 100 edits. A new edit discards the redo branch. Undo is not a permanent deleted-content archive.

Archive a Space to remove it from normal active work; permanent deletion is a separate action for archived user Spaces. Export a package before deleting anything you may need again.

Open document/video editor tabs protect their resources from deletion or cross-Space transfer. Close the affected tabs first, resolving Save, Discard or Cancel as prompted.
