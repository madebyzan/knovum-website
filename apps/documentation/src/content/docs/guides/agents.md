---
title: Use desktop Agents
description: Connect installed executors and understand separate authentication and permissions.
---

## Check the executor first

Settings lists supported desktop Agents, installation status and connection requirements. Follow the specific Agent’s help links, install its required executable and complete its own login before enabling it in Knovum. Detection is not proof that the account has access or that a task will succeed.

Enable the desired Agent, then choose it for a compatible conversation or creation operation. An external Agent does not automatically inherit a Knovum provider key; its own authentication, subscription and configuration apply.

## Give a bounded task

State the intended output and relevant source scope. Review granted tools and files, especially when a task can change content or run commands. An executor being installed is not a reason to permit all files on the computer.

Follow the Run/task status rather than assuming closing a panel stops durable work. Inspect outputs and source trails before relying on them. A failed task remains a failure; it does not authorize silently using a different Agent.

## Extensions are per executor

Skills, plugins and MCP connections are managed through the Agent extension surfaces. Availability depends on what that executor supports. Configure an extension for the intended Agent instead of assuming every Agent shares one universal extension directory.
